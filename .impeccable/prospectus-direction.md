# Direction: THE PROSPECTUS (locked by user)

THESIS: banuacoder.com is an institutional prospectus: a printed monograph for a studio that has shipped real systems since 2019. It refuses the software-house default (rounded cards, gradient hero, stock mockups, tracked-mono eyebrow soup).
OWN-WORLD: Two alternating "plates": ULTRAMARINE plate (#0B1FD0, white text, hairline rules rgba(255,255,255,.25), tonal-lift numerals #1634F0, cyan #3DE0F2 as the single signal) and CHALK plate (#F1F3F9, navy ink #060B2E). Dark mode: chalk plates become navy ink #060B2E. Zero border radius, zero shadow, 1px hairlines, strict 12-col grid, giant tonal numerals (class .numeral), "folio" labels (class .folio: № 01 / SECTION), running header/footer with page counts. Type: Geist 700 display, tight -0.045em, huge (use --fs-84/--fs-64); Inter body; JetBrains Mono only for folios and figures. No gradients, no glass, no emoji, no icon tiles, no cards with shadows. Tokens live in src/styles/global.css (@theme + .plate/.plate-chalk/.folio/.display/.numeral). Legacy bnc-* token names still exist and now map to this palette.
STORY: A buyer (pemda, startup, Flutter dev) should feel "this is an established, serious engineering studio" within one viewport, then see real proof (numbers from real content: 18 case studies, 7 public-sector, since 2019), then book a call.
FIRST VIEWPORT (home): full ultramarine plate. Left: giant headline "Sistem digital yang dibangun untuk bertahan." (EN: "Digital systems built to last."), sub line, primary white button "Jadwalkan Diskusi" (opens booking), secondary underlined link. Right/bottom: oversized tonal numeral "19" (since 2019). Bottom stats strip with hairline columns (18 studi kasus, 7 sektor publik, stack, 2019 berdiri) computed from content. Top: hairline nav, wordmark left, "Jadwalkan panggilan →" right. Folio top right "Laporan Kerja 2019—2026 / Palu".
SIGNATURE: section transitions are plate flips (ultramarine ⇄ chalk) with a numbered folio (№ 02 / Layanan) and a giant tonal numeral; scrolling pins nothing, reveals are masked line rises (existing data-split / data-reveal attributes), numerals parallax slowly (data-parallax).
RULES: AA contrast (plate-mute for secondary text on plates, accent-ink for cyan text on chalk), visible focus rings (2px cyan on plates, 2px plate-blue on chalk), reduced-motion respected, no horizontal overflow at 390px, all copy keeps id + en, keep ClientRouter and animations.ts hooks working, keep real content only.
