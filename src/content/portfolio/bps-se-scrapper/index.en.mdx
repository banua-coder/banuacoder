## Context

BPS SE Scrapper was built to support Badan Pusat Statistik's Sensus Ekonomi (Economic
Census) 2026. The Economic Census is a program BPS runs periodically to capture economic
activity across Indonesia. One of its needs is to record merchants that sell on e-commerce
platforms, whose data is spread across many platforms with different structures.

The project sits closer to data engineering than to typical application development. The
priorities were tool reliability, data accuracy, and how easily results can be traced.

## What We Built

The tool has an extension and a dashboard:

- **Chrome extension**: Runs in the browser and collects merchant data from Tokopedia,
  Shopee, GrabFood, GoFood, Lazada, and Blibli. Each platform has its own collector because
  each exposes its data differently. Regions are selected following the BPS hierarchy, from
  province down to district. Results can be downloaded as Excel, CSV, or JSON, or sent to the
  dashboard through an API.
- **Web dashboard**: A Next.js application with user authentication, SQLite and Parquet
  storage, a regency/city-level choropleth map, and a DuckDB WASM SQL query editor for
  analysis directly in the browser.

## Impact

Merchant data from six platforms is collected with one tool, then mapped and analyzed in
the dashboard without recording each merchant by hand. The project is now archived.
